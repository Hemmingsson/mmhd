# Mattias Music Hoarding Disorder

Personal music library with Bandcamp purchase and wishlist sync and a Discogs catalog for browsing records by label, artist alias, release or pressing.

- Label profiles, parent labels and sublabels, artist aliases and group memberships.
- Edition matching, track credits, catalog numbers, artwork, genres and styles.
- Album grouping, credit cleanup, duplicate review and reversible metadata backfills.
- Spotify playlist imports, SpotiFLAC, Soulseek and a custom library interface.

Install from this checkout with `./scripts/install-mmhd.sh`.

Based on [MusicHoarder](https://github.com/Jeffreyyvdb/MusicHoarder).
